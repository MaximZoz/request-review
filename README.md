# Разбор входящей заявки

Учебная страница и API. Имитатор AI не ходит в сеть: он специально возвращает таймаут и пустой JSON.

Пустой ввод, таймаут и ответ модели с кодом 200, но без темы или с черновиком из пробелов, не становятся готовым результатом. API отдаёт ошибку, черновик очищается, заявка остаётся на ручной разбор.

Менеджеру это полезно тем, что на экране не остаётся пустой «готовый» ответ и клиенту не уходит текст из пробелов. Заявку видно как ручную работу, а не как разобранную.

## Запуск

```bash
python -m unittest test_app.py
python app.py
```

Страница: http://127.0.0.1:8765

В поле заявки слово «таймаут» имитирует обрыв, слово «битый» — некорректный JSON модели.
